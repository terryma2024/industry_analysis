# raw

按行业保存原始资料和原始数据。这里是 LLM Wiki 的不可变来源层，内容尽量保持原貌，不在原始文件上直接改写结论。

每个行业目录固定包含：

- `documents/`: PDF、政策、论文、财报、研报、网页导出。
- `data/`: CSV、XLSX、JSON、统计表、下载的数据集。

## 全局收件箱

- `_inbox/articles/`: 未归类网页、文章、博客和媒体稿。
- `_inbox/papers/`: 未归类论文、PDF 和深度报告。
- `_inbox/transcripts/`: 视频、播客、会议和访谈转录。
- `_inbox/news/`: 临时新闻摘要所需的原文、网页抽取和补充来源。
- `_archive/`: 已完成摄入但暂不归属具体行业的来源归档。

原则：`raw/` 只读、可追溯；总结、判断、实体和概念页面写入 `knowledge/`。
