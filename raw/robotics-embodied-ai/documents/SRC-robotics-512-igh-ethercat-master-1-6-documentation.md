# IgH EtherCAT Master 1.6 documentation

IgH EtherCAT Master 1.6.10

## General information

This HTML contains the complete code documentation.

The API documentations are in the [modules section](https://docs.etherlab.org/ethercat/1.6/doxygen/modules.html).

A list of all native network card drivers can be found [here](https://docs.etherlab.org/ethercat/1.6/doxygen/devicedrivers.html).

A [second userspace library](https://docs.etherlab.org/ethercat/1.6/doxygen/libfakeethercat.html) can be used for a dry-run mode or simulating Process Data.

For information how to build and install, see the INSTALL file in the source root.
