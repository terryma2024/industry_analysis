# Omniverse Replicator synthetic-data pipeline

## Omni Replicator

NVIDIA [Omniverse Replicator](https://developer.nvidia.com/omniverse/replicator) is a core extension of the Omniverse platform that lets developers easily build custom synthetic data generation (SDG) tools and pipelines.

[Overview](https://docs.omniverse.nvidia.com/extensions/latest/ext_replicator.html#replicator-overview) and [Tutorials](https://docs.omniverse.nvidia.com/extensions/latest/ext_replicator.html#replicator-tutorials)

You can also find code snippets for Replicator, tutorial code, and more at our [GitHub Examples](https://github.com/NVIDIA-Omniverse/synthetic-data-examples) page.
