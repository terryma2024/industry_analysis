# 腾讯云与 IO-AI 联合推出具身智能数据平台

## 数据为翼，云端赋能——腾讯云存储联合艾欧智能发布具身智能数据平台

[社区首页](https://developer.cloud.tencent.com/) > [专栏](https://developer.cloud.tencent.com/column) >数据为翼，云端赋能——腾讯云存储联合艾欧智能发布具身智能数据平台

![](https://developer.qcloudimg.com/http-save/yehe-5909132/4b65f1826a7b3dee28971290a79480d8.gif)

**产业背景**

2025 年以来，具身智能机器人行业迎来爆发，人形机器人加速走向量产落地。然而数据采集碎片化、PB 级数据难以高效管理、训练与推理链路割裂，成为制约产业提速的核心瓶颈。腾讯云对象存储（COS）与具身智能数据领军企业艾欧智能（IO-AI）宣布战略合作，联合推出一站式数据平台，打通数据采集到仿真推理的全链路闭环。

**合作双方**

艾欧智能（IO-AI）是国际领先的具身智能数据服务商，核心产品覆盖通用遥操作系统和艾欧数据平台。后者提供采集、清洗、标注、管理到训练输出的全流程能力，已积累超50万条开源数据，覆盖数十个场景和数百种操作对象。

腾讯云存储以 COS 为核心构建 Data Platform 方案，集成 GooseFS、MetaInsight 等组件，专为 AI 训练和推理场景优化，为具身智能行业提供从存储到数据治理的完整底座。

**联合方案：六环节全链路闭环**

**1\. 端侧数采 — 艾欧智能数据平台**

兼容50+机器人形态，支持视觉、运动学、触觉、音频多模态同步采集，内置格式标准化与初步质检，采集数据直接推送至用户的腾讯云 COS 存储桶。接口文档齐全时， **一周内即可完成对接** 。

![](https://developer.qcloudimg.com/http-save/yehe-5909132/844301cf0384258089776e69ed3e07fa.jpg)

**2\. 海量存储 — 腾讯云 COS**

无容量上限、无格式限制，天然支持视频、点云等非结构化数据。提供多 AZ 冗余、跨地域复制、 生命周期冷热分层，以及服务端加密和细粒度访问控制，满足 PB 级具身数据的高可用与合规存储需求。

**3\. 存算加速 — GooseFS**

腾讯云自研分布式缓存加速文件系统，在 COS 与训练集群之间构建高速通道。多级内存/SSD 缓存将训练数据提前预热至本地，实现 **单客户端 40 Gbps 吞吐、亚毫秒时延** ，以 POSIX 接口兼容现有训练框架，零改造即可接入。

**4\. 数据治理 — MetaInsight**

腾讯云数据万象旗下智能检索与数据治理产品，与 COS 深度集成。支持 **自然语言检索** 机器人操作视频（如"抓取失败案例"），自动提取视频帧元数据，跨模态关联分析，并完整记录数据血缘链路，将海量原始数据转化为可检索的数据资产。

**5\. 分布式训练 — 腾讯云 THPC**

自研高性能计算平台，节点间互联带宽达 **3.2 Tbps** ，支持亿级参数模型分布式训练。内置弹性扩缩容与高级调度策略（优先级队列、Gang Scheduling），原生集成 COS/GooseFS 数据通道，算力与存储无缝衔接。

**6\. 模型推理 — HAI + Tairos**

**Tairos（钛螺丝）** 是腾讯 Robotics X 实验室与福田实验室联合发布的国内首个模块化具身智能开放平台，提供规划大模型、多模态感知模型、仿真工具与数据服务，广泛适配工业与人形 机器人。 **HAI（高性能应用服务）** 提供即插即用 GPU/NPU 算力，深度集成 Tairos，从模型上传到推理接口可调用 **最快数分钟** 完成，支持推理集群弹性伸缩。

腾讯云具身智能生态，打通数据采集到仿真推理的全链路闭环。

![](https://developer.qcloudimg.com/http-save/yehe-5909132/7b55f2a82d78551c9bce80c62b29a02f.png)

**客户收益**

**1\. 效率提升：** 数采直推 COS，GooseFS 自动预热，THPC 拉起训练，全链路周期 **压缩 60% 以上** 。

**2\. 成本优化：** 弹性算力按需计费，COS 冷热分层使冷数据存储成本 **降低 70%** **以上** 。

**3\. 数据资产化：** MetaInsight 沉淀可检索多模态数据资产，形成采集→训练→仿真→应用的 **正向数据飞轮** 。

**4\. 安全合规：** 端到端加密、细粒度鉴权、完整审计日志，多客户数据严格隔离。

**5\. 快速落地：** 标准化 API 与开箱即用模板，团队精力聚焦策略模型研发，无需自建数据基础设施 。

**结语**

具身智能的竞争，本质是数据与算法的竞争。腾讯云与艾欧智能以"专业数采 + 云原生存储 + 高性能算力 + 具身模型推理"的完整方案，为机器人企业铺设从数据到智能的高速公路。 **数据是具身智能的燃料，云是具身智能的引擎** ——期待与更多机器人企业携手，共同推动具身智能产业加速走向规模化商业落地。
