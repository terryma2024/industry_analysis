# Daimon DM-Tac X tactile sensor

<video controls="" data-src="/template/index/pc/images/product2/锋锐设计探入细微之处.mp4" src=""></video>

## 锋锐设计 探入细微之处

28° 锋锐尖头设计，尺寸精小，轻松进入狭窄空间执行精细操作。

<video controls="" data-src="/template/index/pc/images/product2/高频率数据采集.mp4" src=""></video>

## 高频率数据采集

已集成接触形貌、三维形变场（全分辨率）、三维分布力（全分辨率），  
六维集中力（三维集中力、三维集中力矩）等模态信息，实现对触觉信息的实时捕捉与精准解析，  
触觉感知性能达国际领先水平。

<video controls="" data-src="/template/index/pc/images/product2/120Hz高频率数据采集.mp4" src=""></video>

## 120Hz 高频率数据采集

实时捕捉快速接触与力变化，  
提升抓取与精细操作的响应能力和稳定性。

![11W 个感知单元](https://www.dmrobot.com/template/index/pc/images/product2/product2-5.jpg "11W 个感知单元")

## 11W 个感知单元

每平方厘米数万个感知单元，细节捕捉无遗漏。

多平台支持

兼容 CPU/GPU 及端侧算力板  
灵活部署，无需更换硬件

![触觉可视，一屏掌控](https://www.dmrobot.com/template/index/pc/images/product2/product2-7.jpg "触觉可视，一屏掌控")

提供 UI 界面

## 触觉可视，一屏掌控

直观显示传感器表面的形变、力变化，让操作更便捷，数据监控更高效。
