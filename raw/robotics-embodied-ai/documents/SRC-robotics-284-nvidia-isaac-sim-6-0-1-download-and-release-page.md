# NVIDIA Isaac Sim 6.0.1 download and release page

> [!warning] Warning
> - Omniverse Launcher, Nucleus Workstation, and Nucleus Cache will be deprecated and will no longer be available starting October 1, 2025.
> - For those who want to use Nucleus and Live Sync after October 1, 2025, please use [Enterprise Nucleus Server](https://docs.omniverse.nvidia.com/nucleus/latest/enterprise.html "(in Omniverse Nucleus)").
> - Nucleus Cache is replaced by [Hub Workstation Cache](https://docs.omniverse.nvidia.com/utilities/latest/cache/hub-workstation.html "(in Omniverse Utilities)").

> [!note] Note
> - Using the latest version of Isaac Sim is recommended to receive the latest security patches and bug-fixes.
> - By downloading or using the NVIDIA Isaac Sim WebRTC Streaming Client, you agree to the [NVIDIA Isaac Sim WebRTC Streaming Client License Agreement](https://docs.isaacsim.omniverse.nvidia.com/6.0.1/common/license-isaac-sim-webrtc-streaming-client.html).
> - The Isaac Sim WebRTC Streaming Client is a native desktop application for connecting to a headless Isaac Sim instance. As an alternative, a [web-based viewer](https://docs.isaacsim.omniverse.nvidia.com/6.0.1/installation/manual_livestream_clients.html#isaac-sim-web-streaming-client) can be deployed via Docker Compose with no client installation required. See [Livestream Clients](https://docs.isaacsim.omniverse.nvidia.com/6.0.1/installation/manual_livestream_clients.html#isaac-sim-manual-livestream-client) for a comparison of both options.
