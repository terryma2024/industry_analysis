# 情绪消费研究中的IP权利与收入暴露

## 一句话理解

消费者喜欢某个IP，不代表销售该IP商品的上市公司拥有版权、获得全部利润，或能把这一收入长期留住。

## 四个不同的权利/口径

| 名称 | 需要核验的内容 |
|---|---|
| 自有版权 | 创作/收购合同、范围及有效性 |
| 独家/非独家艺术家授权 | 地域、期限、品类、分成与最低支付 |
| 外部商业IP授权 | 续约、最低保证金、销售地域和产品范围 |
| 正版商品分销 | 供货合同和商品毛利，不自然取得IP权利 |

## 收入暴露的用法

`披露相关业务外部收入÷合并收入`只能提供代理指标。TOP TOY外部收入、九木全部零售收入、广博创意产品类、奥飞玩具收入不是可互换定义；更不能自动等于18—35岁的情绪消费收入。分析应依次核验权利、终端客户、收入、利润、现金、股东权益。

泡泡玛特艺术家IP也涉及授权；布鲁可以外部IP产品开发为重要商业模式，详见[[emotional-consumption/research-notes/china-emotional-value-physical-goods-stock-screen-2026-10-22|主报告]]及其001/002来源。
