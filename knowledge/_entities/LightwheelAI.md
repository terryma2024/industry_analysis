# 光轮智能

光轮智能是一家 2023 年成立的中国物理 AI 数据与仿真基础设施公司，从自动驾驶合成数据切入，现扩展到 SimReady 物理资产、第一视角人类行为数据、机器人仿真训练、模型评测与真实部署反馈闭环。

## 实体卡片

| 字段 | 当前结论 |
|---|---|
| 工商主体 | 光轮智能（北京）科技有限公司；二手工商页面记录成立于 2023-01-16 |
| 创始人 | 谢晨，创始人兼 CEO；早期资料称曾负责 NVIDIA、Cruise、蔚来自动驾驶仿真 |
| 联合创始人 | 杨海波，当前公开身份为联合创始人兼总裁 |
| 产业链位置 | 具身智能/自动驾驶的训练数据、物理仿真、评测与部署反馈基础设施 |
| 核心产品 | SimReady Library、EgoSuite、RoboFinals、Lightwheel Platform Enterprise；底层技术叙事为 SimFoundry |
| 技术生态 | OpenUSD、NVIDIA Isaac Sim/Isaac Lab/GR00T、Newton；公开 LW-BenchHub、LeIsaac、资产与格式转换工具 |
| 商业状态 | 有具名合作、工厂部署和大额新增订单披露，但审计收入、毛利、现金流、回款和复购结构未公开 |
| 融资状态 | 2023–2026 多轮融资；2026 年公开出现两笔各 10 亿元融资及一轮未披露金额融资，轮次命名存在二手资料差异 |

## 一句话判断

**光轮智能已越过“只有概念和 Demo”的阶段，但尚未越过“仅靠公开信息即可验证高质量规模收入”的阶段。**
