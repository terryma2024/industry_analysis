# Andrej Karpathy

Andrej Karpathy 是 LLM Wiki 模式的提出者之一。当前仓库关注他的相关性不在个人履历，而在他提出的知识管理范式：让 LLM 把原始资料增量编译成持久、互链、可审计的 Markdown wiki。
