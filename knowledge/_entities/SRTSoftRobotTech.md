# SRT 软体机器人

> [!summary]
> 北京软体机器人科技股份有限公司（SRT）成立于 2016 年，以气动柔性末端执行器为产品原点，向机器视觉、智能制造整线、仓储、半导体设备、康复医疗和教育实训扩展。公司是国家级专精特新“小巨人”，未上市；2026 年公开管理层为董事长赵鑫与 CTO 鲍磊。

## 关键事实

| 字段 | 内容 |
|---|---|
| 成立 | 2016-03-16 |
| 总部 | 北京经济技术开发区 |
| 核心产品 | SFG 柔性夹爪、ISC 内撑夹具、VFC 范德华力吸盘及气动控制模块 |
| 主要场景 | 食品生鲜、3C、汽车零部件、五金、半导体、医疗康复、教育 |
| 资质 | 国家级专精特新“小巨人”；Pavlov H1901 披露二类医疗器械注册证 |
| 融资 | 公开可识别约 3.1 亿元以上；精确总额、最新估值待验证 |
| 当前关注点 | 创始人兼原 CEO 高少龙及两名前高管于 2026 年另行创业的团队迁移风险 |

## 研究判断

SRT 应被视为“机器人核心部件 + 专用自动化方案”公司，而不是通用人形机器人或具身大模型公司。它的优势在柔性材料、气腔结构、制造一致性、驱控和行业应用工程；估值关键是标准品收入占比、毛利、复购、回款和海外渠道，而不是 Demo 数量或“软体灵巧手”称谓。
