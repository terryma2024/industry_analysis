# 情绪价值实体消费：相关能力与职业边界

本轮为R09股票筛选，**没有完成招聘JD或薪酬调查**。以下是依据业务链提出的能力方向，属于分析假设，不表示公司正在招聘。

| 岗位族群 | 可迁移能力 | 验证作品 |
|---|---|---|
| IP/产品企划 | 用户研究、版权理解、系列规划 | 原创IP小系列及用户付费测试 |
| 工业设计/结构 | 雕刻、版型、建模、可制造性 | 打样、材料选择与质量记录 |
| 零售/商品运营 | 动销、补货、库存与店铺核算 | 单SKU/门店贡献利润和库存分析 |
| 供应链/品质 | 排产、工艺、验货与交付 | 小批量交付和缺陷闭环 |

下一轮应采集真实JD，区分品牌方、授权方、工厂与零售渠道的需求，再讨论城市、年资和薪酬。创业机会参见[[emotional-consumption/research-notes/china-emotional-value-physical-goods-stock-screen-2026-10-22#七、中小型创业者的机会|小团队验证路径]]。
