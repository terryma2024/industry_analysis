## Transcript Excerpt

每天一个开源项目，今天给大家推荐一个开源 AI 设计工作台，叫 OpenDesign 这个项目目前在 GitHub 上已经有72.3K star。现在很多人都会用 AI 生成网页原型、产品界面、 PPT 海报，甚至图片和视频。但常见的问题是，生成出来的内容经常散在聊天记录里。风格不统一，修改起来也不够直观。而 open design 就是一个开源版的 ai 设计工作台，它可以生成外部原型。移动端界面、桌面端界面、数据看板、演示文稿、图片和视频。你可以把它理解成一个从想法到设计稿。再到可交付文件的 AI 设计平台。打开 open design 之后，首页可以先选择一个技能，比如我们选择生成产品原型。输入你的设计需求，然后点击生成，右侧就会直接出现预览画面。它不是单纯给你一段文字，而是直接生成一个可以看的页面原型。如果你觉得按钮太大、布局太挤或者颜色不太合适，可以继续在对话里让它修改。比如让它调整间距、更换风格。增加模块或者重新优化视觉层级。这样做原型的时候就不用每次从零开始改，而是可以一边看效果一边继续调整。生成完成之后，Open Design 还支持多种格式导出。比如可以导出 HTML 也可以导出 PDF PPTX MP4等格式。这样不管是做产品原型、做方案汇报，还是做演示材料。都会快很多。它还支持和 CodeX Cursor Cloud Code 等工具配合使用。前面可以先用 OpenDesign 生成设计方向和页面原型。后面再交给代码工具继续开发，整个流程会更接近从想法到原型，再到代码落地。接下来教大家如何一分钟完成私有化部署？首先打开浏览器，输入 cloud dot c lost dot two e n 进入控制台之后找到应用商店。然后搜索 OpenDesign 点击部署应用，等待应用状态变成 running 之后，点击公网地址，就可以看到 OpenDesign 已经部署好了。不过这里要注意刚部署完成之后，如果还没有配置模型 API 很多生成功能是没办法正常使用的。所以我们还需要回到 Celo 控制台，再次搜索。 Cloud dot CIA loss dot ruin dot 进入 Home 页面之后，找到 AI Proxy 在这里可以看到模型调用地址以及对应的密钥。把地址和密钥复制下来，然后回到 OpenDesign 进入模型配置页面，把刚才复制的地址和密钥粘贴进去，保存之后先点击测试。如果看到连接成功，就说明模型已经配置好了。接着回到 OpenDesign 首页，选择一个模板，输入设计需求，然后点击生成。如果页面可以正常生成出来，就说明 OpenDesign 已经可以正常使用了。到这里， OpenDesign 的部署和模型配置就全部完成了。之后你就可以用它生成网页原型、移动端界面、数据看板、 PPT 或者其他设计内容。然后大家可以扫码添加我们的交流群，部署或者使用过程中遇到问题。群里都有技术同学实时解答。这里是 GitHub 开源社区，如果你有好的开源项目，欢迎在评论区留言分享。本期的应用推荐就结束了。我们下期再见！
