# 脑机接口 - 研究入口

> [!summary]
> 脑机接口连接神经信号与外部设备，短期最现实的商业路径在医疗康复、辅助沟通、神经调控和科研设备。 当前初步判断：BCI 属于未来健康和未来信息交叉方向，中国科研、非侵入式设备和康复场景活跃，但侵入式临床、长期安全和支付闭环仍处早期。

## 当前摘要

- 一句话理解：脑机接口连接神经信号与外部设备，短期最现实的商业路径在医疗康复、辅助沟通、神经调控和科研设备。
- 当前判断：BCI 属于未来健康和未来信息交叉方向，中国科研、非侵入式设备和康复场景活跃，但侵入式临床、长期安全和支付闭环仍处早期。
- 关键不确定性：侵入式植入长期安全、临床有效性、审批路径、数据伦理、医保/商业支付和消费级产品真实复购待验证。
- 下一步优先问题：补脑机接口专项政策、NMPA 创新医疗器械审评案例、国内公司融资/临床数据、医院临床试验登记和伦理规范。

## 行业边界

- 包含：侵入式/半侵入式/非侵入式 BCI、神经信号采集、解码算法、康复机器人联动、脑控输入、神经调控。
- 不包含：泛心理健康 App、普通 EEG 玩具和没有闭环控制/临床价值的消费电子概念。
- 相邻行业：生物医药、医疗器械、AI、机器人康复、XR、神经科学。

## 中国十五五定位

- 国家重视原因：脑科学、重大疾病康复、老龄化、医疗器械自主可控和未来健康产业。
- 对应战略方向：未来健康、未来信息、人工智能+医疗、脑科学与类脑研究。
- 中国产业链位置：高校医院科研和非侵入设备基础较强；植入电极、长期临床数据和高端神经芯片仍需突破。
- 政策受益环节：创新医疗器械、康复医疗、脑科学平台、数据合规和医院试点。
