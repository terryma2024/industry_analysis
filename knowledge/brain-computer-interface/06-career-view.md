# 脑机接口 - 求职与学习视角

## 适合的软件/平台背景切入点

- 平台工程：数据平台、仿真/调度/监控、设备管理、权限和工作流系统。
- 行业解决方案：把技术能力翻译成客户 ROI、验收指标和交付计划。
- 数据与 AI：数据治理、模型评测、算法工程、可观测性和安全合规。
- 产品/项目：跨研发、客户、监管和供应链推进落地。

## 角色族群

| 角色 | 需要的能力 | 作品集/验证项目 |
| --- | --- | --- |
| 行业研究/投资分析 | 政策、产业链、财务、技术基本功 | 公司池、政策追踪表、订单验证笔记 |
| 平台/后端工程 | 数据建模、任务调度、可观测性、权限、可靠性 | 行业设备/项目管理 demo、指标看板 |
| 产品经理/解决方案 | 客户流程、验收指标、合规、安全边界 | 场景方案、ROI 模型、交付 SOP |
| 数据/AI 工程 | 数据管线、评测、模型服务、质量控制 | 数据闭环或评测平台 demo |
| 政策/合规/注册 | 标准、监管、审批、文档体系 | 监管路径图、证据清单模板 |

## 学习路径

1. 先读本行业 `00-index` 和 `01-industry-map`，明确边界和价值流。
2. 选 3 家代表公司读年报/官网/招聘，建立岗位和产品词表。
3. 做一个小型作品集：公司池、政策追踪表、场景 ROI 或设备运营看板。
4. 用 JD 验证技能差距，区分硬门槛和可补齐行业知识。
