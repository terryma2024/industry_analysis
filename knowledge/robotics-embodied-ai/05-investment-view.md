# 机器人（具身智能） - 投资视角

> [!warning] 边界
> 本文是行业研究与投资框架，不构成证券买卖建议。现阶段重点是识别产业链价值位置、验证指标和反证条件；目标价、仓位、交易时点需在单家公司财务模型和估值比较之后再做。

## 一句话判断

具身智能是“政策确定性强、远期空间大、短期商业化分化剧烈”的早期产业。投资上不宜只押注人形整机叙事，第一优先应看能被多个整机路线复用的核心零部件、传感/视觉、运动控制和具备真实场景数据的工业/仓储机器人公司。

## 投资假设

- 核心 thesis：
  - 中国在工业机器人部署、硬件供应链、制造场景和政策组织能力上具备优势，具身智能有机会从“工业/仓储/特种作业”先落地，再向商业服务和家庭服务扩散。
  - 未来 3-5 年，收益更确定的环节可能不是所有人形整机厂，而是进入多家客户供应链、随行业出货放大的核心零部件和工业场景解决方案。
  - 人形机器人整机仍值得跟踪，但应以收入、交付、复购、客户生产场景效率、毛利和现金消耗验证，不以 demo、融资额和发布会热度作为核心依据。
- 时间 horizon：
  - 0-12 个月：主题热度和政策催化驱动，核心看订单、样机验证、小批量交付、供应链入围。
  - 1-3 年：工业制造、仓储物流、巡检、特种作业先进入商业化验证期。
  - 3-5 年：若成本下降、数据闭环和安全标准成熟，通用人形机器人可能进入更大规模放量。
- 中国政策催化：
  - 工信部《人形机器人创新发展指导意见》设定 2025/2027 阶段目标，明确“大脑、小脑、肢体”、核心部组件、专用操作系统、典型场景和标准体系。证据：`SRC-robotics-001` `SRC-robotics-002`
  - “机器人+”应用行动把制造、农业、物流、医疗、养老、应急等纳入应用推广。证据：`SRC-robotics-003`
  - 十五五未来产业叙事已把具身智能放入未来产业方向。证据：`SRC-robotics-004`
  - 人形机器人与具身智能标准化技术委员会成立，说明行业将进入标准、测试、安全、接口规范阶段。证据：`SRC-robotics-005`
- 关键催化剂：
  - 头部整机厂从小批量示范进入持续交付。
  - 上游核心零部件企业出现机器人相关收入占比提升，而不是只停留在送样。
  - 工业/仓储/巡检客户披露采购、复购或产线部署。
  - 标准体系明确接口、安全、测试、分级评价。
  - NVIDIA Isaac/GR00T、国内具身模型和仿真/数据平台推动开发门槛下降。证据：`SRC-robotics-017` `SRC-robotics-018`
- 估值锚：
  - 整机公司：收入增长、毛利率、订单质量、现金消耗、客户集中度。
  - 零部件公司：机器人业务收入占比、客户数量、单机价值量、毛利率、产能利用率。
  - 工业机器人/AMR 公司：现有收入、销量、海外占比、软件/服务收入、项目交付质量。
  - 平台软件/数据公司：数据闭环能力、生态开发者、真实场景覆盖、算力和模型成本。

## 事实、估计、判断与假设

| 类型 | 内容 | 证据/状态 |
|---|---|---|
| 事实 | 中国工业机器人产量和服务机器人产量继续增长，2025 年统计公报披露工业机器人 77.3 万套、同比 28.0%，服务机器人 1858.1 万套、同比 16.1%。 | `SRC-robotics-006` `SRC-robotics-007` |
| 事实 | IFR World Robotics 2025 显示中国仍是全球最大工业机器人市场，2024 年安装量约占全球 54%，国产厂商国内份额首次超过外资。 | `SRC-robotics-008` |
| 事实 | 优必选 2025 年全尺寸具身智能人形机器人收入和销量出现明显增长，收入成为其第一大业务，但公司仍亏损。 | `SRC-robotics-009` `SRC-robotics-033` |
| 事实 | 绿的谐波 2025 年收入和利润高增长，并披露工业机器人份额提升、具身智能机器人业务规模增长是原因之一。 | `SRC-robotics-034` |
| 事实 | 新松机器人 2025 年收入约 41.22 亿元，各类机器人销量同比增长约 65%，同时布局具身智能研究院。 | `SRC-robotics-035` |
| 估计 | 人形机器人单机零部件价值量中，执行器、减速器、电机、丝杠、传感器、视觉系统可能是主要成本和利润池。 | 待用年报、拆机、供应链资料继续验证 |
| 判断 | 中国最先商业化的场景大概率不是家庭陪伴，而是工业制造、仓储物流、巡检、特种作业和数据采集。 | 政策场景、公司产品、现有机器人商业化路径交叉支持 |
| 判断 | 零部件和工业场景公司短期确定性高于纯人形整机；纯整机弹性高但淘汰率也高。 | 行业早期规律 + 当前财务可验证性 |
| 假设 | 2027 年前行业会从“样机竞赛”转向“交付、效率、成本、标准、售后”的真实竞争。 | 待用订单、交付和标准进展验证 |

## 投资主线

### 主线一：核心零部件优先

这一主线的投资逻辑是“卖铲子”：不确定哪家整机最后胜出，但减速器、电机、执行器、丝杠、力传感器、3D视觉、控制器会被多条路线复用。

| 环节 | 代表公司 | 关注理由 | 主要验证指标 |
|---|---|---|---|
| 谐波/RV减速器 | 绿的谐波、双环传动/环动科技、中大力德、秦川机床 | 机器人关节核心部件，国产替代和单机用量弹性 | 机器人客户数量、销量、毛利率、产能、价格降幅 |
| 无框/空心杯电机 | 步科股份、鸣志电器、禾川科技、汇川技术 | 关节和灵巧手核心驱动 | 批量订单、客户入围、产品代际、单机价值量 |
| 丝杠/轴承/精密传动 | 秦川机床、贝斯特、长盛轴承、五洲新春、北特科技 | 线性执行器和灵巧手潜在高壁垒环节 | 送样到量产转化、精度等级、良率、产能 |
| 力/触觉传感器 | 柯力传感、东华测试、汉威科技 | 灵巧操作和安全交互所需 | 送样数量、批量订单、产品一致性、算法解耦能力 |
| 3D视觉/激光雷达 | 奥比中光、速腾聚创、禾赛科技、舜宇光学 | 空间感知和导航基础 | 机器人收入占比、客户结构、ASP 和毛利 |

**初步判断**：这是当前最适合做基本面跟踪的一组。若整机厂出货超预期，它们受益；若某一家整机失败，它们未必被单点拖垮。风险是市场已经提前定价、竞争导致 ASP 下滑、客户验证周期长。

### 主线二：有财报验证的整机和工业机器人公司

这一主线不是只看“人形”，而是看谁已经有工业机器人、协作机器人、AMR、半导体机器人或系统集成收入，再用具身智能作为第二曲线。

| 公司 | 看点 | 主要风险 |
|---|---|---|
| 优必选 | 港股上市，已披露全尺寸具身智能人形机器人收入、销量、毛利和亏损；是观察人形机器人商业化最直接样本之一。 | 净亏损仍大；订单是否来自可持续商业客户、是否复购、效率是否足以替代人工仍需验证。 |
| 新松机器人 | 工业、移动、特种、半导体机器人产品线完整，2025 年收入和销量有规模；具身智能作为前沿布局。 | 传统系统集成和工业机器人毛利压力；具身智能短期可能贡献有限。 |
| 埃斯顿 | 工业机器人国产龙头之一，运动控制和自动化基础强。 | 人形/具身收入占比需拆分，不能把传统工业机器人全部按具身智能估值。 |
| 埃夫特 | 工业机器人和跨行业智能制造解决方案，科创板上市，具备工业客户场景。 | 项目制和集成业务盈利波动，海外/认证/交付成本。 |
| 越疆 DOBOT | 协作机器人基础强，并扩展到人形、轮式、多足等具身智能产品。 | 具身智能业务占比和盈利质量需在财报中拆解。 |

**初步判断**：这组适合做“低空飞行”：不是弹性最大，但能用财务数据校准行业热度。重点是分清传统机器人收入、AI/具身新增收入和一次性订单。

### 主线三：场景先行的 AMR/移动操作/仓储机器人

通用人形机器人很吸引眼球，但商业化可能先发生在“场景强约束”的工业和仓储里。AMR 公司拥有真实客户、调度系统、场景数据和售后网络，若加上机械臂/操作能力，可能比纯人形更快创造 ROI。

| 公司 | 看点 | 主要风险 |
|---|---|---|
| 极智嘉 Geek+ | AMR 市场和仓储场景基础强，若通用仓储机器人落地，可形成数据和客户复用。 | 仓储资本开支周期、价格竞争、人形仓储机器人实际效率需验证。 |
| 快仓 Quicktron | AMR 部署规模、仓储软件和海外客户基础。 | 与具身智能关联需要看操作能力，而非仅搬运能力。 |
| 优艾智合 YOUIBOT | 工业物流和巡检运维，强调移动操作和“一脑多态”。 | 未上市，财务、毛利、客户结构需进一步验证。 |
| 仙工智能、斯坦德、海柔创新 | 工业移动机器人/仓储系统生态。 | 场景分散、竞争激烈、项目交付压力。 |

**初步判断**：这组对于你的职业转型也很重要。它们需要软件平台、调度系统、数据闭环、客户交付和行业解决方案能力，和互联网/软件工程管理经验更接近。

### 主线四：高弹性人形整机创业公司

这组是弹性最大、风险也最大的方向。宇树、智元、逐际、星动、银河、自变量、魔法原子、傅利叶、乐聚、松延、开普勒等公司都值得跟踪，但未上市公司要严控证据质量。

| 判断维度 | 好信号 | 坏信号 |
|---|---|---|
| 产品 | 标准化产品、明确参数、可购买/可交付 | 只有舞台 demo，没有价格、参数和交付 |
| 客户 | 工业/仓储/商业客户明确，客户愿意公开案例 | 只有融资新闻和模糊订单 |
| 数据闭环 | 有真实场景数据采集、仿真、训练、评测平台 | 只有大模型口号 |
| 供应链 | 自研核心模块或绑定可靠供应商 | 高度依赖外购且无法降本 |
| 财务 | 订单、收入、交付节奏逐步可验证 | 估值快速上升但收入缺位 |

**初步判断**：整机创业公司适合做“观察池”和一级市场/职业机会跟踪。二级市场若通过供应链映射参与，应优先验证供应商是否真正量产供货，而不是仅有概念关联。

## 阶段性投资结论

| 结论 | 置信度 | 理由 |
|---|---:|---|
| 核心零部件比纯整机更适合作为第一阶段投资分析主线 | 高 | 多客户复用、财务更可验证、受益于国产替代 |
| 工业/仓储/巡检比家庭服务更可能先商业化 | 中高 | 场景付费方明确、ROI 可测、政策支持制造业应用 |
| 人形整机会继续有高热度，但分化会非常剧烈 | 高 | 技术、供应链、资金、客户和安全要求都很高 |
| 中国具身智能的政策确定性强，但不等于每家公司都有投资价值 | 高 | 政策支持行业，不保证单个公司盈利 |
| 软件/数据/仿真平台是中长期关键变量，但国内可投标的暂时不清晰 | 中 | 技术重要性高，商业模式和上市标的仍待识别 |

## 风险

- 技术风险：
  - 灵巧操作、长周期自主任务、复杂环境泛化、安全人机协同仍未完全解决。
  - 仿真到现实、数据规模、VLA 模型、运动控制和硬件可靠性任何一环不达标，都会拖慢商业化。
- 商业化风险：
  - 工业客户可能先采购用于展示、试点或数据采集，不代表形成持续 ROI。
  - 人形机器人效率可能低于人工或专机自动化，导致真实替代节奏慢。
  - 售后维护、停机责任、安全事故和保险成本可能高于市场预期。
- 政策风险：
  - 政策支持可能带来地方重复建设和产能过剩。
  - 安全、数据、伦理、产品认证标准趋严，可能延长落地周期。
- 竞争风险：
  - 整机厂数量快速增加，价格战和同质化风险高。
  - 上游零部件若快速扩产，ASP 和毛利可能下行。
  - 海外龙头在基础模型、算力、芯片和生态上仍有优势。
- 估值风险：
  - 当前市场容易把“远期万亿空间”提前贴现到所有概念股。
  - 很多公司机器人业务收入占比很低，估值却按机器人重估，存在业绩兑现压力。

## 反证条件

- 什么事实会推翻当前判断：
  - 2026-2027 年头部整机厂交付停留在展示/试点，无法形成复购和生产效率提升。
  - 核心零部件公司机器人相关收入未能从送样、小批量进入可披露规模。
  - 工业/仓储客户明确表示人形/移动操作机器人 ROI 不成立，采购大幅放缓。
  - 安全事故或监管限制导致主要场景无法开放。
  - 海外平台形成事实标准，国内公司只能做低毛利硬件代工。
- 哪些指标需要持续跟踪：
  - 人形机器人交付台数、订单金额、客户类型、复购情况。
  - 机器人在真实工位的效率：相对人工效率、良率、稳定工作时长、维护成本。
  - 核心零部件出货量、ASP、毛利率、产能利用率。
  - 工业机器人/AMR 产销量和海外收入。
  - 政策标准、测试认证、地方补贴和示范项目。
  - 招聘结构：机器人数据、仿真、运动控制、MLOps、云端运维、现场交付岗位是否持续增加。

## 下一步研究任务

1. 为第一优先核心零部件公司建立单独跟踪表：产品、客户、机器人收入、毛利、产能、估值。
2. 深挖优必选 2025 年报：收入结构、毛利、亏损、订单、客户、现金、研发投入。
3. 建立“整机厂 - 供应商 - 场景客户”映射表，避免只看概念关联。
4. 抽样 30-50 个招聘 JD，验证职业转型需要补的能力栈。
5. 对比中国、美国、日本、欧洲路线：整机、零部件、平台、应用场景分别谁强。
