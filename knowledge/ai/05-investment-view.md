# AI相关 - 投资视角

> [!warning]
> 本页是研究框架，不是投资建议。AI 主题估值容易提前反映远期叙事，必须用收入、毛利率、客户复购、算力成本和监管里程碑反复校准。

## 投资假设

- 核心 thesis：十五五阶段，中国 AI 投资主线更可能从“谁的大模型最强”转向“谁掌握算力、入口、数据、行业工作流和合规能力”。
- 时间 horizon：1-2 年看算力、云、AI 办公/客服/营销、数据评测和政策催化；3-5 年看 Agent、行业 AI、具身智能和科学智能。
- 中国政策催化：人工智能+行动、国产算力、数据要素、模型备案、安全评测、行业示范和地方算力券。
- 关键催化剂：国产算力集群交付、模型 API/订阅收入增长、企业续费率提升、AI 应用进入核心流程、监管路径清晰。
- 估值锚：算力/芯片看订单和毛利；云平台看 AI 云收入和资本开支回报；应用看 ARR/留存/毛利；数据服务看高价值后训练与评测占比。

## 分层投资观察

| 层级 | 初步吸引力 | 关键证据 | 主要风险 |
| --- | --- | --- | --- |
| 国产算力 | 政策确定性强 | 芯片/服务器/集群订单、生态迁移、利用率 | 估值、供给、性能/成本、制裁 |
| 云与模型平台 | 收入入口清晰 | API 调用、企业客户、开发者生态 | 价格战、毛利率、同质化 |
| AI 应用/Agent | 长期空间大 | 付费留存、流程嵌入、真实 ROI | 幻觉、安全、项目制交付重 |
| 数据/评测/安全 | 被低估的基础设施 | 专家数据、红队、安全评测、模型备案服务 | 客户自建、毛利率、规模有限 |
| 基础模型创业 | 技术弹性大 | 模型能力、成本效率、生态影响力 | 商业模式、算力、融资和竞争 |

## 风险

- 技术风险：模型能力趋同、开源压价、Agent 成功率不足、评测失真。
- 商业化风险：C 端免费心智强，B 端项目制重，企业 ROI 难证明。
- 政策风险：生成式 AI、数据、版权、内容安全、行业准入和出口管制不确定。
- 竞争风险：大厂内置 AI 可能挤压独立应用；模型 API 价格战压缩利润。
- 估值风险：主题拥挤，容易把 3-5 年后的利润提前折现。

## 反证条件

- 国产算力无法规模交付或生态迁移失败。
- 企业 AI 应用无法从试点转为续费/复购。
- 推理成本下降只带来价格战，没有带来应用收入增长。
- 监管明显收紧，模型上线和数据使用成本大幅提高。

| 指标 | 为什么重要 | 数据来源 | 更新频率 |
| --- | --- | --- | --- |

| GPU/国产算力集群订单 | 判断算力瓶颈和国产替代 | 招标、公司公告、财报 | 月/季 |

| 企业续费率/ARR | 判断应用 ROI | 公司财报、招股书、访谈 | 季度/年度 |
| 推理价格和延迟 | 判断应用成本曲线 | API 价格页、benchmark | 月度 |
| 高价值数据收入占比 | 判断数据服务升级 | 海天瑞声等财报、公司披露 | 半年/年度 |
